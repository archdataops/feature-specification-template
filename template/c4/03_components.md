# C4. Уровень 3: компоненты

*Крупные части одного контейнера. Рисуйте только для контейнера, где живёт основная логика. Хватает 4–7 блоков.*

```plantuml
@startuml
!include <C4/C4_Component>
LAYOUT_WITH_LEGEND()
title Уровень 3. Компоненты контейнера «Сервис»

Container(caller, "Кто вызывает", "Технология")
ContainerDb(db, "База данных", "Технология")

Container_Boundary(svc, "Сервис") {
  Component(api, "Обработчики API", "Технология", "Какие методы принимает")
  Component(logic, "Бизнес-логика", "Технология", "Правила и статусы")
  Component(data, "Доступ к данным", "Технология", "С какими таблицами работает")
}

Rel(caller, api, "Запросы", "REST/JSON")
Rel(api, logic, "Вызывает")
Rel(logic, data, "Читает и пишет")
Rel(data, db, "SQL")
@enduml
```

| Компонент | Ответственность | Связь со спецификацией |
|-----------|-----------------|------------------------|
| *Название* | *За что отвечает* | *Методы API, правила BR-xx, переходы T-xx, таблицы* |

> [!TIP]
> Колонка «Связь со спецификацией» показывает, где в коде будет реализовано каждое требование. Если правило из раздела 10 не попадает ни в один компонент, его, скорее всего, забудут.
